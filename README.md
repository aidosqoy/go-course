# Go Mentoring

Курс для изучения языка программирования Go с нуля.

## О курсе

- Основан на [Go Tour](https://www.gocat.dev/tour/) — интерактивном учебнике от создателей Go
- Еженедельные встречи с ментором
- Домашние задания после каждой темы
- Код-ревью от ментора

## Структура курса

| Неделя | Тема | Уроки Go Tour |
|--------|------|---------------|
| 1 | [Введение в Go](./week-01/) | 1-13 |
| 2 | [Типы и константы](./week-02/) | 14-19 |
| 3 | [Управляющие конструкции](./week-03/) | 20-27 |
| 4 | [Switch и Defer](./week-04/) | 28-32 |
| 5 | [Указатели и структуры](./week-05/) | 33-37 |

## Как учиться

1. **Изучи теорию** — пройди уроки на [Go Tour](https://www.gocat.dev/tour/)
2. **Выполни домашние задания** — они в папке `homework/` каждой недели
3. **Создай PR для ревью** — ментор проверит твой код
4. **Обсуди вопросы** — на встрече или в чате

## Как начать

1. Клонируй репозиторий
2. Прочитай [CONTRIBUTING.md](./CONTRIBUTING.md) — там подробная инструкция
3. Переключись на свою ветку
4. Начни с [Недели 1](./week-01/)
