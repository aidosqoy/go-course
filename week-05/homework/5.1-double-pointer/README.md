# ДЗ 5.1: Удвоение через указатель

## Цель
Понять разницу между передачей по значению и по указателю.

## Что нужно сделать

Написать две функции:
1. `DoubleValue(n int) int` — принимает значение, возвращает удвоенное
2. `DoublePointer(n *int)` — принимает указатель, изменяет значение напрямую

## Сигнатуры функций

```go
func DoubleValue(n int) int
func DoublePointer(n *int)
```

## Пример использования

```go
func main() {
    // Передача по значению
    a := 5
    b := DoubleValue(a)
    fmt.Println("a:", a, "b:", b) // a: 5 b: 10 (a не изменилось!)

    // Передача по указателю
    c := 5
    DoublePointer(&c)
    fmt.Println("c:", c) // c: 10 (c изменилось!)
}
```
