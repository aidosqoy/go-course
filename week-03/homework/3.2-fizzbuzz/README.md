# ДЗ 3.2: FizzBuzz

## Цель
Решить классическую задачу с собеседований.

## Что нужно сделать

Написать функцию, которая выводит числа от 1 до n по правилам:
- Если число делится на 3 — вывести "Fizz"
- Если число делится на 5 — вывести "Buzz"
- Если число делится на 3 И на 5 — вывести "FizzBuzz"
- Иначе — вывести само число

## Сигнатура функции

```go
func FizzBuzz(n int)
```

## Пример использования

```go
func main() {
    FizzBuzz(15)
}
```

## Ожидаемый вывод

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

## Критерии выполнения

- [ ] Правильный порядок проверок (сначала на 15, потом на 3 и 5)
- [ ] Вывод соответствует ожидаемому
- [ ] Код читаемый и понятный
