# ДЗ 3.1: Проверка на простое число

## Цель
Научиться писать функции с циклами и условиями.

## Что нужно сделать

Написать функцию, которая проверяет, является ли число простым.

## Напоминание

Простое число — это число больше 1, которое делится только на 1 и само себя.

## Сигнатура функции

```go
func IsPrime(n int) bool
```

## Пример использования

```go
func main() {
    fmt.Println(IsPrime(2))   // true
    fmt.Println(IsPrime(3))   // true
    fmt.Println(IsPrime(4))   // false
    fmt.Println(IsPrime(17))  // true
    fmt.Println(IsPrime(18))  // false
    fmt.Println(IsPrime(1))   // false (1 не простое!)
    fmt.Println(IsPrime(-5))  // false (отрицательные не простые)
}
```

## Критерии выполнения

- [ ] Корректно обрабатывает числа ≤ 1
- [ ] Корректно определяет простые числа
- [ ] Оптимизация: проверка до √n (не обязательно, но желательно)
