# ДЗ 3.3: Факториал

## Цель
Написать функцию с проверкой входных данных.

## Что нужно сделать

Написать функцию вычисления факториала числа.

## Напоминание

`n! = 1 × 2 × 3 × ... × n`, при этом `0! = 1`

## Сигнатура функции

```go
func Factorial(n int) (int, error)
```

## Пример использования

```go
func main() {
    result, err := Factorial(5)
    if err != nil {
        fmt.Println("Ошибка:", err)
    } else {
        fmt.Println("5! =", result) // 5! = 120
    }

    result, err = Factorial(0)
    fmt.Println("0! =", result) // 0! = 1

    result, err = Factorial(-3)
    fmt.Println(err) // факториал отрицательного числа не определён
}
```

## Тестовые значения

| n | n! |
|---|-----|
| 0 | 1 |
| 1 | 1 |
| 5 | 120 |
| 10 | 3628800 |
| -1 | ошибка |

## Критерии выполнения

- [ ] Функция возвращает ошибку для отрицательных чисел
- [ ] Правильно обрабатывает 0! = 1
- [ ] Результаты совпадают с тестовыми значениями
