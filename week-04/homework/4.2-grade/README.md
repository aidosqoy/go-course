# ДЗ 4.2: Оценка по баллам

## Цель
Использовать switch без условия для диапазонов значений.

## Что нужно сделать

Написать функцию, которая переводит баллы (0-100) в буквенную оценку.

## Шкала оценок

| Баллы | Оценка |
|-------|--------|
| 90-100 | A |
| 80-89 | B |
| 70-79 | C |
| 60-69 | D |
| 0-59 | F |
| < 0 или > 100 | Некорректный балл |

## Сигнатура функции

```go
func Grade(score int) string
```

## Пример использования

```go
func main() {
    fmt.Println(Grade(95))  // A
    fmt.Println(Grade(82))  // B
    fmt.Println(Grade(71))  // C
    fmt.Println(Grade(65))  // D
    fmt.Println(Grade(45))  // F
    fmt.Println(Grade(-5))  // Некорректный балл
    fmt.Println(Grade(105)) // Некорректный балл
}
```

## Критерии выполнения

- [ ] Используется switch без условия (не `switch score`)
- [ ] Все диапазоны обрабатываются правильно
- [ ] Некорректные баллы возвращают сообщение об ошибке
