# ДЗ 4.1: Название дня недели

## Цель
Освоить оператор switch.

## Что нужно сделать

Написать функцию, которая по номеру дня возвращает его название.

## Сигнатура функции

```go
func DayName(n int) string
```

## Пример использования

```go
func main() {
    fmt.Println(DayName(1)) // Понедельник
    fmt.Println(DayName(5)) // Пятница
    fmt.Println(DayName(7)) // Воскресенье
    fmt.Println(DayName(0)) // Некорректный день
    fmt.Println(DayName(8)) // Некорректный день
}
```

## Критерии выполнения

- [ ] Используется switch (не цепочка if-else)
- [ ] Дни с 1 (Понедельник) по 7 (Воскресенье)
- [ ] Некорректные значения обрабатываются через default
