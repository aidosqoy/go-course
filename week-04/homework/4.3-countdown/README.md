# ДЗ 4.3: Обратный отсчёт с defer

## Цель
Понять порядок выполнения defer (LIFO — последний вошёл, первый вышел).

## Что нужно сделать

Написать функцию обратного отсчёта, используя defer для демонстрации порядка выполнения.

## Сигнатура функции

```go
func Countdown(n int)
```

## Пример использования

```go
func main() {
    Countdown(5)
}
```

## Ожидаемый вывод

```
5
4
3
2
1
Поехали!
```

## Критерии выполнения

- [ ] Используется defer
- [ ] Числа выводятся от n до 1
- [ ] "Поехали!" выводится в конце
- [ ] Студент может объяснить, почему так работает
