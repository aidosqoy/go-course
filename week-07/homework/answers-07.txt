1. Что вернёт обращение к несуществующему ключу map?
Го вернет нулевое значения типа value самой мапы

2. Как проверить, существует ли ключ в map?
el, ok := map[k]. Если да то ok = true, если нет ok = false

3. Можно ли итерировать по map в определённом порядке?
Нет, в мапе порядок всегда рандомный

4. Что произойдёт при записи в nil map?
Будет паника, потому что nil map она не инициализирована

5. Можно ли использовать слайс как ключ map? Почему?
Нет, ключ в мапе должен быть сравнимым. А слайс можно сравнивать только с nil. Слайс по сути это структура
с указателем, с длиной и с капасити, то есть не само значение данных.
