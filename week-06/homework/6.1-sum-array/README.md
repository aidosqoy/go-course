# ДЗ 6.1: Операции с массивом

## Цель
Научиться работать с массивами и выполнять базовые операции.

## Что нужно сделать

1. Написать функцию `Sum` — возвращает сумму всех элементов массива
2. Написать функцию `Average` — возвращает среднее арифметическое
3. Написать функцию `Max` — возвращает максимальный элемент
4. Написать функцию `Min` — возвращает минимальный элемент

## Сигнатуры

```go
func Sum(arr [5]int) int
func Average(arr [5]int) float64
func Max(arr [5]int) int
func Min(arr [5]int) int
```

## Пример использования

```go
func main() {
    arr := [5]int{10, 20, 5, 15, 30}

    fmt.Println("Сумма:", Sum(arr))         // 80
    fmt.Println("Среднее:", Average(arr))   // 16
    fmt.Println("Максимум:", Max(arr))      // 30
    fmt.Println("Минимум:", Min(arr))       // 5
}
```

## Критерии выполнения

- [ ] Sum корректно суммирует элементы
- [ ] Average возвращает правильное среднее (float64)
- [ ] Max находит максимальный элемент
- [ ] Min находит минимальный элемент
