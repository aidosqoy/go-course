# ДЗ 6.3: Фильтрация и преобразование слайсов

## Цель
Научиться фильтровать и преобразовывать слайсы.

## Что нужно сделать

1. Написать функцию `FilterEven` — возвращает только чётные числа
2. Написать функцию `FilterPositive` — возвращает только положительные числа
3. Написать функцию `Double` — умножает каждый элемент на 2
4. Написать функцию `Reverse` — переворачивает слайс

## Сигнатуры

```go
func FilterEven(nums []int) []int
func FilterPositive(nums []int) []int
func Double(nums []int) []int
func Reverse(nums []int) []int
```

## Пример использования

```go
func main() {
    nums := []int{-3, -1, 0, 1, 2, 3, 4, 5}

    even := FilterEven(nums)         // [0, 2, 4]
    positive := FilterPositive(nums) // [1, 2, 3, 4, 5]
    doubled := Double(nums)          // [-6, -2, 0, 2, 4, 6, 8, 10]
    reversed := Reverse(nums)        // [5, 4, 3, 2, 1, 0, -1, -3]
}
```

## Подсказки

- Для фильтрации создай новый пустой слайс и добавляй подходящие элементы
- Double должен возвращать новый слайс, не изменяя оригинал
- Для Reverse можно создать новый слайс или поменять элементы местами

## Критерии выполнения

- [ ] FilterEven корректно отбирает чётные числа
- [ ] FilterPositive отбирает только положительные (> 0)
- [ ] Double возвращает новый слайс с удвоенными значениями
- [ ] Reverse корректно переворачивает слайс
- [ ] Оригинальный слайс не изменяется
