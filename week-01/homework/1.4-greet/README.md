# ДЗ 1.4: Приветствие пользователя

## Цель
Научиться работать со строками и форматированным выводом.

## Что нужно сделать

Написать функцию `Greet`, которая принимает имя пользователя и возвращает строку приветствия.

## Сигнатура функции

```go
func Greet(name string) string
```

## Пример использования

```go
func main() {
    message := Greet("Алексей")
    fmt.Println(message) // Привет, Алексей! Добро пожаловать в мир Go!

    fmt.Println(Greet("Мария")) // Привет, Мария! Добро пожаловать в мир Go!
}
```

## Дополнительно (бонус)

Добавить проверку на пустое имя — если имя пустое, вернуть "Привет, незнакомец!".

## Критерии выполнения

- [ ] Функция возвращает корректное приветствие
- [ ] Работает с разными именами
- [ ] (Бонус) Обрабатывает пустую строку
