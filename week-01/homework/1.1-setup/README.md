# ДЗ 1.1: Настройка окружения

## Цель
Подготовить рабочее окружение для разработки на Go.

## Что нужно сделать

1. Установить Go с официального сайта https://go.dev/dl/
2. Настроить IDE на выбор:
   - **GoLand** (рекомендуем) — [бесплатная студенческая лицензия](https://www.jetbrains.com/shop/eform/students)
   - VS Code + расширение Go
3. Написать программу "Hello, World" и успешно запустить

## Как проверить

```bash
# Проверить установку Go
go version

# Запустить программу
go run main.go
```

## Ожидаемый результат

```
Hello, World!
```

## Критерии выполнения

- [ ] Go установлен, команда `go version` работает
- [ ] IDE настроена, подсветка синтаксиса работает
- [ ] Программа запускается без ошибок
