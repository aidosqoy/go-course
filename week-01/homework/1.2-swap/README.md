# ДЗ 1.2: Функция swap

## Цель
Научиться писать функции с несколькими возвращаемыми значениями.

## Что нужно сделать

Написать функцию `swap`, которая принимает два целых числа и возвращает их в обратном порядке.

## Сигнатура функции

```go
func swap(a, b int) (int, int)
```

## Пример использования

```go
func main() {
    x, y := 10, 20
    fmt.Println("До swap:", x, y)    // До swap: 10 20

    x, y = swap(x, y)
    fmt.Println("После swap:", x, y) // После swap: 20 10
}
```

## Критерии выполнения

- [ ] Функция возвращает два значения в обратном порядке
- [ ] Демонстрация работы в main()
- [ ] Код отформатирован (`go fmt`)
