# ДЗ 1.3: Площадь и периметр круга

## Цель
Закрепить работу с именованными возвращаемыми значениями и типом float64.

## Что нужно сделать

Написать функцию `Circle`, которая по радиусу вычисляет площадь и периметр (длину окружности) круга.

## Формулы

- Площадь: `S = π × r²`
- Периметр: `P = 2 × π × r`

## Сигнатура функции

```go
func Circle(radius float64) (area, perimeter float64)
```

## Пример использования

```go
func main() {
    a, p := Circle(5)
    fmt.Printf("Радиус: 5\n")
    fmt.Printf("Площадь: %.2f\n", a)    // Площадь: 78.54
    fmt.Printf("Периметр: %.2f\n", p)   // Периметр: 31.42
}
```

## Критерии выполнения

- [ ] Функция использует именованные возвращаемые значения
- [ ] Результаты математически корректны
- [ ] Протестировано на нескольких значениях радиуса
