# ДЗ 2.4: Калькулятор ИМТ

## Цель
Применить знания о типах и преобразованиях в практической задаче.

## Что нужно сделать

Написать функцию расчёта индекса массы тела (ИМТ) и функцию интерпретации результата.

## Формула ИМТ

```
ИМТ = вес (кг) / рост (м)²
```

## Интерпретация

| ИМТ | Категория |
|-----|-----------|
| < 18.5 | Недостаточный вес |
| 18.5 - 24.9 | Норма |
| 25.0 - 29.9 | Избыточный вес |
| ≥ 30 | Ожирение |

## Сигнатуры функций

```go
func CalculateBMI(weightKg, heightCm float64) float64
func InterpretBMI(bmi float64) string
```

## Пример использования

```go
func main() {
    bmi := CalculateBMI(70, 175) // вес 70 кг, рост 175 см
    fmt.Printf("ИМТ: %.1f\n", bmi)           // ИМТ: 22.9
    fmt.Println(InterpretBMI(bmi))            // Норма
}
```

## Важно

Рост передаётся в **сантиметрах**, но в формуле нужны **метры**!

## Критерии выполнения

- [ ] Функция CalculateBMI корректно переводит см в метры
- [ ] Функция InterpretBMI возвращает правильную категорию
- [ ] Проверено на нескольких примерах
